# Ночные голоса

Статический атлас сов северной Евразии: каталог, страница вида, фотографии, схема ареала и запись голоса. В набор входят 18 видов фауны бывшего СССР, от сипухи до рыбного филина. База данных и сборка не нужны.

## Локально

```
node server.mjs
```

Откройте http://localhost:8080

## На обычном сервере

Скопируйте папку целиком и укажите её корнем сайта. Подойдут nginx, Apache, IIS и любой хостинг статики. Отдельные правила для адресов не нужны: страницы видов открываются через якорь `#/латинское-имя`.

Пример для nginx:

```
server {
    listen 80;
    server_name example.com;
    root /var/www/owl-voices;
    index index.html;
}
```

## Лицензии

Фотографии взяты с Wikimedia Commons и iNaturalist. Записи голосов — с Xeno-canto. Автор, источник и лицензия указаны на странице каждого вида: их нужно сохранять.

Часть записей выпущена под CC BY-NC-SA. Их можно слушать в некоммерческом учебном проекте, но нельзя использовать в коммерческих целях.
